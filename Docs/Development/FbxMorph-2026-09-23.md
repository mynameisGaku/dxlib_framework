# モーフの読込・再生（2026-09-23）

ソース版DxLibのモデル確定前の接続へ位置・法線差分を渡す。
対象は1チャンネル1ターゲット。複数モーフ、スキンとの併用、標本化した変形量の再生、個体別の手動上書きに対応する。
再生時は変形量だけを更新し、形状差分は読み直さない。変形処理はDxLibの既存処理であり、GPUモーフの実装ではない。
中間ターゲット、負の目標重み、頂点別重み付き差分、範囲外の変形量は拒否する。法線差分がなければ警告して基本法線を保つ。

今回の確認:
- Debug / ReleaseのCTest各23/23成功。変形量の補間、上書き解除、記録時点の保存、名前衝突回避を含む。
- 実DxLibでスキンと複数モーフを持つ2体を描画。片方だけの形状変化、クリップによる変形、一時停止を確認。
- 頂点色、追加UV、基本照明、2D復元、従来の骨アニメーションの実描画試験も成功。
- 配布物のビルド・インストール・外部利用の7段階が成功。
- ログはBuild/FbxContinuation/morph-*、画像は同ディレクトリ下model-smoke/morph-*.png。

生成したメッシュ名がファイル内ノードと衝突する問題も修正し、同名候補を持つ頂点色モデルの実描画を回帰に追加した。
SDK未導入環境の検証は未実施。PBRとファイル内カメラ／ライトはこの段階には含めていない。
