# 基本PBR（2026-09-23）

ufbxの金属度・粗さ系材質から基本係数とベーステクスチャを保持し、DxLibの既存スキンVSと独自GGX PSで描画する。
公式ソースは変更せず、照合したフックをビルド先のコピーへ挿入する。拡張番号は3。

## 実描画で確認したもの

- 正面からの白色光、正射影、線形ベース色(0.8,0.3,0.1)、金属度0.75、粗さ0.7で、独立に求めたsRGBの(131,87,53)と実画素が一致。
- ファイルから読み込んだ金属度・粗さと、同じ値の手動指定で画素が一致。
- ファイルのUV1指定と明示UV1指定が一致し、UV0へ変えると画素が変化。
- スキンアニメーションを保ち、粗さと金属度を変更した個体だけ描画色が変化。
- 非照明の隣接モデルは画素が一致し、2Dの色も0xff4020を保持。
- 同じプロセスで全セッションを2回実行し、解放済みGPU資源を再利用しない。
- 組み込みVSのCOLOR1をPS入力宣言から省くと入力レジスターがずれ黒くなる問題を修正。上記の基準色比較がこの回帰も検出する。
- 古いバックエンドはPBRモデルを読み込んだふりをせず、描画失敗時もライト・2D状態を復元。

結果ログ：Build/FbxContinuation/pbr-*-tests.log、pbr-package.log。
法線・金属度・粗さのマップ等は部分読込の警告を残す。完全なDCC材質再現やGPU性能計測ではない。
SDK未導入の別Windows環境での検証は未実施。

## 最終検証

Debug／ReleaseともCTest 23/23成功。モデル単体30/30、ToolsのPythonテスト19件成功。
配布検証はbuild-configure/build/install/consumer-configure/consumer-build/consumer-run/support-only-runの7段階が成功。
