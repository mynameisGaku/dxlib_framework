# FBXの静止カメラ・ライト（2026-09-23）

透視・正射影カメラ、指向性・点・スポットライトを公開メタデータへ保持し、明示的にビューへ適用する。
原点・向き・単位の変換、光の強度、適用失敗時の元設定保持を検証する。
ufbx 0.23.0でtarget_camera_axesを指定しない場合、projection_axesが有効にならないため、FBXの既定の+X前方/+Y上方を使用する。
過去の検証記録の書き換えではなく、この変更に対する記録。

- モデル単体：28件成功。
- 実描画：点光源の位置、スポットの方向で照明ありモデルだけ変わり、非照明の隣接モデルの画素は一致。
- 正射影：カメラを奥行き方向へ動かしても非照明モデルの画素が一致。
- ファイルの透視カメラで描画した後の2D色は0xff4020。
- Debug／Release：CTest各23/23成功。
- 配布検証：7段階成功、support単独リンク・実行も成功。
- 記録：Build/FbxContinuation/scene-*-tests.log、scene-package.log。

1ビューで選択するモデル用ライトは1個。CPU形状の既存照明とは別系統。
減衰係数は利用側の明示指定、面・体積ライトと影は非対応、カメラ／ライトは静止情報のみ。
SDK未導入の別PCでの検証は引き続き未実施。
