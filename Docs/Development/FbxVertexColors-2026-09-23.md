# FBX頂点色の検証（2026-09-23）

ufbxから最初の頂点色セットを読み、材質拡散色との積を頂点共有判定に含める。
DxLibの.x読込はメッシュを専用の子フレームへ配置し、材質別に分割するため、子フレームの全メッシュへ頂点色を有効化する。
ネイティブ側のフレーム欠落・設定失敗はモデルを解放して失敗を返す。

今回再実行した検証:
- Debug / ReleaseのCTestはそれぞれ23/23成功（NoStlと実描画を含む）。
- 実描画でRGB三角形の各優勢色が存在し、拡散色0.5を一度だけ掛けた最大成分が100〜129に入ることを確認。
- 頂点色画像を目視確認。既存の2体の独立再生、テクスチャ、再読み込み、日本語パス、終了後描画の試験も成功。
- 単体試験で色の保持、範囲外の拒否、材質分割メッシュの設定、設定失敗時の解放を確認。

ログはBuild/FbxContinuation/colors-{debug,release}-{build,tests}.log、画像は同ディレクトリ下model-smoke/vertex-colors.png。
8ビットの色精度、先頭色セットのみという制限がある。これは追加UV・モーフ・PBRの対応完了を示す記録ではない。
SDK未導入環境でのセットアップ検証は引き続き未実施。
