# 変更履歴

## 未リリース — Windows統合

- 添付された0.3.0 ZIPの275ファイルをSHA-256照合して取り込みました。
- WindowsのCreateFont／DrawTextマクロがNative接続部のメンバー名を書き換える不具合を修正し、接続契約テストを追加しました。
- Windowsビルドへ `-Clean` を追加し、ZIP復元時の古い日時によるビルド結果の混在を防ぎます。
- MSVCの実際のインクルード表示を採取してNinjaに渡し、日本語の依存ファイル行の文字化けを回避します。
- CMake CMP0144を対応版で有効にしました。
- [Windows検証の結果と残る制限](WindowsIntegration.md)を記録しました。

## 0.3.0 — 2026-09-12

0.2.0のGit履歴を復元して継続開発。機能の水増しではなく、実行途中の終了・再入・例外・配布検証の失敗経路を修正した版です。

### 描画

- Clear・Nativeコールバック・状態復元が失敗したフレームもエラーを保持し、描画追加とPresentを防止します。
- Begin／Target切り替え／復元／Presentのバックエンド例外を結果型へ変換します。
- Presentの例外後もフレームを閉じ、新しいBeginFrameへ進めます。Target切り替えに失敗しても復元に成功した場合は、元のTargetで続行可能です。

### Sceneとライフサイクル

- Pending Sceneの差し替え時に呼ばれるデストラクタからの、再入Commit／差し替えを拒否します。Shutdownは安全な境界まで保留し、中断された要求を成功扱いにしません。
- Sceneコンストラクタの例外をUserExceptionへ変換。停止後は構築自体を行わず、破棄予約済みのSceneも受け付けません。
- RequestQuitを現在および準備中の子階層へ伝播。実行中コールバックが戻った後、残りの初期化・更新・描画を抑止します。
- 子階層の停止予約と、終了フック・メモリ破棄を別経路にしました。

### 音声と資源

- 音声状態の取得中にShutdownすると次の無効ハンドルを参照してクラッシュする問題を修正しました。
- 音声開始中のShutdownは、生成途中の再生を解放してInvalidStateを返します。
- 音声バックエンドの例外をBackendFailureへ変換し、開始途中や取得失敗した再生を回収します。
- ResourceRegistryの解放対象をコールバック実行前に切り離し、再入Shutdown／CollectUnusedでも二重呼び出しや取りこぼしを防ぎます。

### 検証と互換性

- 先行する25件のC++回帰テストで失敗を再現。音声のRedには実際のプロセスクラッシュ（終了コード139）を含みます。
- 検証スクリプトの3件の失敗テストを追加。古い成功Summaryを残さず、running／failed／passed・実行ID・開始終了日時を記録し、タイムアウトの途中出力も保存します。
- バージョンは検証時にCMakeLists.txtから取得します。
- Native失敗時の動作変更と、ILifecycleGroupへのRequestStop_Internal追加のため、マイナーバージョンを更新しました。ABI互換を保証するものではありません。

実Windows・MSVC・実DxLib SDK・実デバイスの確認結果は含みません。実行した構成・件数は[検証結果](ValidationReport.md)に記載します。

## 0.2.0 — 2026-09-12

0.1.0の配布ソースとGit履歴を復元して継続開発した版です。

### 修正

- SlotMapの削除時、ユーザーデストラクタより前にスロット世代を無効化し、再入する生成を安全にしました。
- 初期化・更新中のCollection終了要求を後続対象へ反映し、終了要求後の余分な処理を防ぎました。
- コンストラクタからCollectionを終了した場合、その生成を成功として返さないようにしました。
- 単独で呼ぶライフサイクル入口でも、OnTick／OnDrawの例外を結果型へ変換します。
- Scene準備中の終了・Quit・自身の破棄要求を処理し、不必要なEnterやグローバル音声スコープの停止を防ぎました。
- パス・フォント名・ウィンドウ名・描画文字のUTF-8／埋め込みNULを検査します。
- 不正な音声保存形式がキャッシュ経由で検証を回避する問題を修正しました。
- 別の音声バックエンドで作ったSoundの再生を拒否します。
- 描画キュー実行に失敗したフレームは、エラーを無視されてもPresentしません。
- nullリソース登録を拒否します。

### 追加

- マウス／Padを含むFInputMap、割り当て解除・変更・クリア、デジタル軸。
- 型付きのFindComponent／GetComponents／FindObject／GetObjects。
- 任意利用のDSpriteRendererComponent。
- 層別CMakeターゲット、install／find_package、インストール先移動後の利用。
- 公式SDKのセットアップ、Windows Debug／Releaseビルド・検証スクリプト、CI設定。
- 12フレームで終了する実SDK用NativeSmoke。日本語パス、画像、文字、RenderTarget、入力取得、任意の音声API検査。
- 再現可能な配布ZIP生成とファイル別SHA-256マニフェスト。

### 検証

C++は95件から127件へ増加。GCC Debug／Release、Clang ASan／UBSanを通過。公開ヘッダー65個の単独コンパイル、パッケージ移動後のリンク・実行、Support層のみの利用を確認。配布スクリプトは6テスト通過。

実Windows・MSVC・実DxLib SDK・実デバイスの実行結果は含みません。
