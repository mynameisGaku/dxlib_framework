# 再配置パッケージの外部利用検証

`ValidatePackage.py` はこのディレクトリの利用者ソースを一時領域へコピーし、再配置したパッケージを `find_package` で構成・リンクします。開発リポジトリのサンプル cpp は参照しません。既存の描画・問い合わせ・キャラクター移動・UI の確認を維持しています。

| 実行対象 | 相互作用の追加確認 |
| --- | --- |
| `PhysicsOnly` | `dxf::physics` だけで2D／3Dの Sensor Begin→Stay→削除 End、バッチの読み直し、問い合わせカテゴリ0の通知、Sensorを支持面にしないこと、Worldを変更しない支持候補、2m/sの移動床、ジャンプの支持速度継承を確認する |
| `Consumer` | `InteractionConsumer.cpp` の共通2D／3Dシーンを正規のSceneNavigatorで更新し、Component配送・通知中の自己破棄・後続配送の抑止・削除End・床追従・ジャンプ・Teleportによる支持解除を確認する |
| `NativeApp` | 既存の2D／3D歩行・2D画素確認に続けて、同じ共通シーンを実Applicationから起動・固定更新・描画し、2D／3Dの完了結果を確認する |

共通シーンは最初の固定更新を静止状態にし、以後は床を毎秒2m移動します。60回目のキャラクターと床のX座標は `2 × 59 / 60` mです。この解析値から、一段遅れの追従や二重移動を検出します。61回目にジャンプ、62回目の結果で速度を繰り返し継承しないことを確認し、Teleport後に支持と領域の履歴を確認します。

`PhysicsOnly` の追加失敗コードは2Dが301〜309、3Dが321〜329です。`Consumer` の共通シーンは2Dが401〜403、3Dが411〜413です。いずれも終了コード0が成功です。`NativeApp` は従来どおり成功時に `NATIVE_CONSUMER_PASSED` を出力します。

必要な最終確認は Native OFF／ON × Debug／Release の配布4構成です。Native ONのビルドと実デバイス実行は別の確認であり、`NativeApp` を起動していない場合は実Applicationの成功とは記録しません。各構成で元の出力を上書きしないrunを使い、空白・日本語を含む再配置先と無関係な作業ディレクトリから検証します。
